# robots.txt — MUMU Solutions
# Updated: 2026-09-22
#
# Policy: only the homepage is indexable. Everything else is denied by the
# Disallow below and opened back up case by case. /llms.txt and /ads.txt are
# two of those exceptions — a file written for crawlers is useless if
# robots.txt hides it, and AdSense flags the domain while ads.txt is
# unreachable.
#
# The home page is allowed as "/$" AND as "/?", and both lines are needed.
# The $ anchors the match to the end of the URL, so "Allow: /$" covers "/" and
# nothing else — every query string falls through to the Disallow below. That
# silently blocked /?lang=en, which this site publishes as the shareable link
# for the English version, for Googlebot and for all four social preview
# crawlers. It also blocked any inbound link carrying a utm_ tag.
#
# Two things must stay allowed for the site to work correctly in search and
# in social previews:
#   * /images/ and /fonts/ — Google renders the page before indexing it. A
#     crawler that cannot fetch the logo, the share image, or the webfonts
#     sees a broken page and judges it accordingly.
#   * every .css and .js the pages load. Google renders a page before judging
#     it, and a crawler that cannot fetch the stylesheet sees a broken one.
#     This list was written when the site had no external script or stylesheet
#     at all, so it missed them — /analytics.js was blocked here and Google
#     duly reported the analytics tag as not installed. That tag is gone now,
#     but the lesson is not: add the next .css or .js here in the same commit
#     that creates it.
#   * the social crawlers below — they fetch og-image.png directly. Blocked,
#     a link shared on WhatsApp or LinkedIn renders as a grey box.

# Content signals — draft-romm-aipref-contentsignals. Declares how we want
# automated systems to use this content. Not enforcement, a stated preference.
#
#   search=yes     build an index and link here. This is how people find us.
#   ai-input=yes   quote and cite us in AI answers, including RAG. Saying no
#                  would contradict /llms.txt, which exists to help exactly
#                  those systems describe us accurately.
#   ai-train=no    do not train or fine-tune models on this content. Training
#                  sends nobody back to us; being cited does.
#
# It sits in the User-agent: * group because a crawler obeys only its most
# specific matching group, and every AI crawler falls under * here — the named
# groups further down are social preview fetchers and the AdSense crawler.
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /$
Allow: /?
Allow: /index.html
Allow: /images/
Allow: /fonts/
Allow: /sitemap.xml
Allow: /llms.txt
Allow: /ads.txt
Allow: /error.css
Allow: /error.js
Disallow: /
